# 📚 ClassControl

Sistema web para gerenciamento escolar desenvolvido para facilitar o controle de usuários, turmas, mensagens e comunicados em uma instituição de ensino.


## 📖 Sobre o Projeto

O **ClassControl** é um painel administrativo moderno desenvolvido utilizando HTML, CSS, JavaScript e Bootstrap.

O sistema permite que coordenadores e administradores acompanhem informações importantes da escola através de um dashboard intuitivo, organizado e responsivo.

O objetivo é centralizar o gerenciamento da instituição em um único ambiente.

# 🔐 Script de Login - ClassControl

## 📖 Descrição

Este arquivo é responsável pela autenticação dos usuários no sistema **ClassControl**, utilizando o **Supabase Authentication**.

Além de realizar o login, o script identifica o perfil do usuário e o direciona automaticamente para o painel correspondente.

---

# 🎯 Objetivo

Garantir que apenas usuários autenticados possam acessar o sistema e que cada perfil seja redirecionado para sua área específica.

---

# ⚙️ Funcionalidades

- Conexão com o Supabase
- Login utilizando e-mail e senha
- Seleção do tipo de usuário
- Validação do perfil selecionado
- Consulta da tabela `usuarios`
- Identificação do tipo de usuário
- Logout automático em caso de perfil incorreto
- Redirecionamento para o dashboard correspondente

---

# 👥 Perfis Suportados

O sistema possui quatro perfis de acesso:

| Perfil | Código |
|---------|--------|
| Administrador | ADM |
| Professor | PROFESSOR |
| Aluno | ALUNO |
| Responsável | RESPONSAVEL |

---

# 📂 Estrutura

```
script.js
│
├── Conexão com Supabase
├── Seleção do perfil
├── Login
├── Consulta ao banco
├── Validação do perfil
├── Logout
└── Redirecionamento
```

---


# 🔗 Conexão

O sistema cria uma conexão utilizando:

- URL do projeto Supabase
- Chave pública (Publishable Key)

```javascript
const supabase = createClient(URL, KEY)
```

---

# 🔑 Processo de Login

O usuário informa:

- E-mail
- Senha

O sistema utiliza:

```javascript
supabase.auth.signInWithPassword()
```

para autenticar o usuário.

---

# 📋 Consulta ao Banco

Após o login, o sistema consulta a tabela:

```
usuarios
```

Obtendo o campo:

```
tipo_de_usuario
```

Esse campo define qual dashboard será carregado.

---

# ✅ Validação do Perfil

O sistema compara:

Perfil escolhido pelo usuário

com

Perfil armazenado no banco.

Caso sejam diferentes:

- Login é cancelado
- Usuário é desconectado
- É exibida uma mensagem de erro

---

# 🚀 Redirecionamentos

Após a validação, o usuário é enviado para seu painel.

## Administrador

```
/dashboards/admin/index.html
```

## Professor

```
/dashboards/professor/index.html
```

## Aluno

```
/dashboards/aluno/index.html
```

## Responsável

```
/dashboards/respon/index.html
```

---

# 🔒 Segurança

O script garante:

- Autenticação por e-mail e senha
- Validação do perfil do usuário
- Logout automático em caso de acesso incorreto
- Redirecionamento seguro para cada dashboard

# Tela de Autenticação Moderna 🚀

Este projeto consiste em uma interface de usuário (UI) limpa, moderna e responsiva para páginas de login ou cadastro. O design conta com um card centralizado, sombras suaves que adicionam profundidade e suporte nativo a duas paletas de cores distintas.

## ✨ Funcionalidades
* **Centralização Absoluta:** O formulário permanece perfeitamente centralizado na tela através do CSS Flexbox, independente da resolução do dispositivo.
* **Duplo Esquema de Cores:** Inclui estilos pré-configurados para uma identidade visual corporativa (Azul) e outra vibrante (Laranja).
* **Estilos de Botões:** Opções de botões preenchidos (sólidos) e com contorno (outline) com efeitos visuais ao passar o mouse (`:hover`).
* **Design Responsivo:** Estrutura fluida que se adapta bem a diferentes tamanhos de monitores e dispositivos móveis.


O projeto foi unificado para facilitar o uso, mas você pode separá-lo em dois arquivos caso prefira:

* `index.html`: Contém a estrutura semântica do formulário de login.
* `style.css`: Contém toda a estilização, variáveis visuais e resets de layout.

# ClassControl - Gerenciamento de Dependentes



## Funcionalidades

- Simulação de um banco de dados local.
- Atualização automática dos dados do aluno.
- Atualização dos indicadores do dashboard.
- Renderização dinâmica do gráfico de desempenho.
- Alteração do status de frequência.
- Inicialização automática do primeiro aluno disponível.

---

## Estrutura dos Dados

Cada aluno é armazenado em um objeto contendo:

| Campo | Descrição |
|--------|-----------|
| inicio | Data de início do curso |
| fim | Data de término do curso |
| horas | Carga horária realizada |
| media | Média geral do aluno |
| comportamento | Avaliação comportamental |
| frequencia | Situação da frequência |
| frequenciaClasse | Classe CSS para estilização |
| notas | Notas utilizadas no gráfico |
| meses | Meses correspondentes às notas |

Exemplo:

```javascript
"João Silva (Técnico em TI)": {
    inicio: "2026-02-01",
    fim: "2026-12-15",
    horas: "120h / 400h",
    media: "8.5",
    comportamento: "Excelente",
    frequencia: "ÓTIMA",
    notas: [7.5, 8.0, 8.5, 9.0],
    meses: ['Fev','Mar','Abr','Mai']
}
```

---

## Fluxo de Funcionamento

### 1. Carregamento da Página

Quando a página termina de carregar (`DOMContentLoaded`):

- cria o banco de dados local;
- registra o evento do menu de seleção;
- carrega automaticamente o primeiro aluno.

---

### 2. Seleção de um Dependente

Sempre que o usuário troca o aluno no `<select>`:

```javascript
seletor.addEventListener('change', (e) => {
    carregarDadosAluno(e.target.value);
});
```

o sistema busca as informações correspondentes e atualiza toda a interface.

---

### 3. Atualização do Dashboard

A função

```javascript
UI_AtualizarDashboard(dados);
```

é responsável por atualizar:

- carga horária;
- média;
- comportamento;
- barra de progresso;
- frequência.

---

### 4. Atualização do Gráfico

O gráfico é atualizado utilizando:

```javascript
renderChart('mainChart', dados.notas, dados.meses);
```

onde:

- `dados.notas` representa os valores do eixo Y;
- `dados.meses` representa os rótulos do eixo X.

---

### 5. Atualização da Frequência

Após atualizar os dados do aluno, o sistema altera dinamicamente a classe CSS da frequência:

```javascript
freqElem.className = `fw-800 mt-1 ${dados.frequenciaClasse}`;
```

Isso permite mudar automaticamente a cor do indicador conforme o status do aluno.

---


